# 嗓子干？嗓子痒？秋季咳嗽不止？什么咳嗽需要及时就医？中医教您“逃过咳嗽季”

> 更新时间：2026-09-17 (UTC+8)

〔中医秋季养肺〕

**如何逃过“咳嗽季”**

生活中有部分人，每每一入秋季，就会开始咳嗽。我们就发现无论是在办公室、地铁、公交车等地方，都会不时听到“咳咳”干咳的声音，从嗓子干、嗓子疼、喉咙痒，慢慢变成咳声不断，短期内还很难治愈，尤其老人和孩子，不少人问道这该怎么办？

今年尤其明显，咳嗽声此起彼伏，那么，为什么一到秋季就容易咳嗽呢？如何辨别不同类型的咳嗽？秋季咳嗽又该如何预防呢？今天我们就来讲讲秋季咳嗽这件事。

**秋天为什么容易咳嗽？**

**1、秋燥伤肺**

许多人一到秋天就咳嗽，但是也没有感冒炎症什么的症状，只是干咳几声，也不咳痰，好像影响不大，这种情况考虑是秋燥伤肺引起的。

从中医的角度来看，秋燥是秋季外感燥邪引起的，更易通过口鼻呼吸道或皮肤毛孔侵入肺部。所以，一些身体状况本身很好的人在秋季也容易出现喉痒、咳嗽等症状。由于秋季“燥邪”当令，而肺“喜润而恶燥”，故秋季“燥邪”伤人最易伤肺。

**2、冷空气刺激呼吸道**

老人、儿童等特殊人群由于自身免疫系统不完善，气候变化使得这些人群在季节交替之时成为疾病侵袭的对象。原本患有慢性肺疾病的患者更容易出现病情加重。

**3、换季感冒**

秋季气候无常，早晚的温差较大。如果感冒不及时治疗好，很容易发展成为支气管炎、肺炎，而出现咳嗽症状。

**4、咽喉炎**

有些人一到秋天就咳嗽，同时还伴有咽喉肿痛、发干、发痒、有异物感等不适症状，有时候咳嗽厉害点还有恶心、干呕，那么这种情况考虑是咽喉炎引起的。

**5、秋季过敏性咳嗽**

一到秋天就咳嗽可能是过敏性咳嗽。过敏性咳嗽持续时间一般比较长，且易反复发作，咳嗽剧烈，早晨起来、活动或哭闹时会加重。夜间咳嗽比白天严重，咳嗽时间长久。

**哪种咳嗽需要看医生？**

**留心症状特点**

1.伴有发热、咳吐黄绿色痰或脓痰的咳嗽。有肺部感染的可能。

2.伴有胸闷气短的咳嗽。有哮喘、肺间质病变等病的可能。

3.痰中带血的咳嗽。需排除肿瘤、支气管扩张、肺部感染、肺结核等疾患。

4.伴有胸痛的咳嗽。需排除肺栓塞、胸膜炎等疾患。

**注意咳嗽声音**

1.伴有声音嘶哑或犬吠样咳嗽。多见于声带或喉部病变及肿瘤等，需尽早治。

2.金属音调样咳嗽。多见于纵隔肿瘤、主动脉瘤或肺癌等。

3.咳嗽终末出现深长的鸡啼样吸气性吼声。多见于小儿易感的百日咳。

**留意****咳嗽时间**

1.连续咳嗽3周不愈。一般感冒咳嗽、急性鼻咽炎咳嗽三周内可愈。

2.反复发作或季节性强的咳嗽。一般春秋季反复发作的咳嗽多为过敏性咳嗽，有发展为支气管哮喘的可能，必须在医生诊治下规范治疗。

3.反复后半夜睡眠中的剧烈咳嗽。应排除咳嗽变异性哮喘及心脏疾病引起的咳嗽。

**三种秋咳，对症拆招**

外感咳嗽主要分为风寒袭肺证、风热犯肺证及风燥伤肺证，根据中医养生理论，食疗、拔罐、刮痧等中医特色疗法对缓解不同的外感咳嗽效果很好。

**风寒袭肺证**

这种证型表现为咳嗽声重、咳白稀痰、流清涕、头痛、恶寒发热等症状，初期症状不严重时，可按摩列缺、尺泽、肺俞等穴位。

具体方法是：取列缺（左右两手虎口交叉，一手食指压在另一手的桡骨茎突上，食指尖到达之凹陷处即是）、尺泽（曲肘，肘横纹中桡侧凹陷处）、肺俞（位于人体背部第三胸椎棘突下，左右旁开二指宽处），用拇指指腹顺时针揉50次左右，再用拇指指腹按压20次左右，有酸胀感为宜。

※若咳嗽咳痰较重，可去医院处理。

**风热犯肺证**

表现为咳嗽频剧、咳痰不爽、痰黏稠或色黄，同时伴有鼻流黄涕、口渴、头痛身热等症状。

初期咳嗽咳少量黄色黏痰时，可服用具有疏风清热、宣肺止咳的中药代茶饮。具体方子是：取桑叶10克、野菊花10克、枇杷叶6克、桔梗10克，将以上药物放入茶杯中用沸水，焖泡10~15分钟即可饮用。使用此法3~5天症状无法缓解，可去医院进行问诊。

也可辅助使用刮痧法治疗，具体方法是：用刮痧板 （质地为水牛角），以脊柱为中心，两侧旁开各1.5寸，从大椎刮至脾俞，重点刮大椎风门、肺俞及督脉。刮痧以皮肤红热为度，对不出痧或出痧较少的部位不强求出痧。

**风燥伤肺证**

风燥咳嗽多干咳无痰，或痰少而黏、不易咳出，或痰中带有血丝，同时伴有咽喉干痛、口鼻干燥。

燥邪犯肺的咳嗽，食疗是比较好的选择，若咳嗽初期干咳无痰，伴咽干咽痛，可服用五汁饮（梨100克、荸荠20克、麦冬10克、龙眼肉10克、莲藕20克、蜂蜜少许，将以上药物放入锅中煎煮30~45分钟，取汤作代茶饮）。

也可食用川贝蒸梨（雪花梨400克、川贝母5克、百合10克、冰糖5克，雪花梨切去蒂部，挖出雪梨心，把川贝粉、百合、冰糖放入雪梨内部，盖回蒂部，放入碗中，隔水蒸30~45分钟即可）。

**哪些食物是“咳嗽救星”**

**1.百合**

百合可以提高肺脏抗毒能力，可以养阴润肺，清心安神，是药食同源的养生佳品百合中含有丰富的黏液质，对镇静咳嗽也有帮助。

**2.雪梨**

雪梨有润燥生津，清热化痰的功效，保持呼吸道的湿润，减少咳嗽和痰液产生，常用来辅助缓解肺燥咳嗽、热病津伤烦渴等症状。 

**3.白萝卜**

白萝卜具有清热解毒和润肺止咳的功效，生吃可清热生津，熟吃则能消食化痰，有助于减少咳嗽和痰液的产生，可以用于秋季养肺。 

**4.马蹄**

马蹄具有降火，补肺凉肝，消食化痰的作用。当肺热咳嗽，痰多黏腻时食用马蹄，会有缓解作用，不过马蹄虽好，也不适合大量食用。 

**5.山药**

山药具有益肺气、养肺阴的功效，也有利于增强脾胃的消化吸收功能。

**6.莲藕**

俗话说“秋藕最补人”，秋天食用莲藕，生食清热生津，熟食健脾开胃，既能润肺、清热、养阴，又能健脾养胃。 

**7.罗汉果**

罗汉果具有很好的降火功效，特别是在燥热伤肺的情况下，用罗汉果泡水饮用，有助于中和体内的燥热，滋润肺部。 

**8.银耳**

银耳作为常见的平价滋补食材，富含胶质，能滋阴润肺、养胃生津，减少干燥和炎症，是秋季润燥佳品，常与红枣、枸杞搭配炖汤。
