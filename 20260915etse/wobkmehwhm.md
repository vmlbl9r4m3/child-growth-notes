# 孕妇便秘可以用药吗  孕妇便秘吃什么药

> 更新时间：2026-09-15 (UTC+8)

孕妇可以适当服用乳果糖口服液、果导片等缓泻类药物，或者也可以使用小麦纤维素颗粒，还可以加服微生态制剂和促动力药物。另外，孕妇也可以对症服用一些中药方剂，像通便方和五味消毒饮等药物都可以作为选择。

由于胎儿不断增大会对肠道产生压迫力，再加上体内激素分泌水平变化，孕妇相较于其他人群就会更容易患上便秘。如果便秘症状轻微，一般经过饮食调理即可改善。但如果严重，可能就要用药治疗。那么，孕妇便秘吃什么药可以治好呢？

**一、孕妇便秘吃西药**

**1、缓泻药**

并不建议孕妇便秘通过吃药的方式治疗，但在经过一般调理方法无效时，就可以在专业医生指导下采用较小的药物。其中可以采用的主要有乳果糖口服液、果导片等缓泻类药物，也可以服用小麦纤维素颗粒一类容积性泻药，复方聚乙二醇也可以作为选择之一。但都要注意不可以长期大剂量服用，以免会影响胎儿健康。

**2、微生态制剂**

乳酸菌片、益生菌素片和双歧杆菌片等微生态制剂类药物，对于便秘有调理作用，而且会在改善肠道菌群分布的基础上达到治疗效果，不会对胎儿产生毒副作用。因此可作为孕妇便秘的首选用药。

**3、促动力药**

如果孕妇肠胃动力不足，就可以酌情加服一些促动力药物。建议可使用健胃消食片，一定要谨慎使用莫沙必利片等药品。

**二、孕妇便秘吃中药**

**1、大肠实热型**

孕妇便秘可以通过服用中药方来调理。如果是属于大肠实热病症，就需要以导滞通幽和清热行气为原则进行治疗，可以煎服由槟榔、大黄、炒枳壳和茯苓等中草药组成的通便方，一般服用2-3个疗程即可见效。

**2、大肠燥热型**

若孕妇患上便秘与大肠燥热有关，就要选择服用主要功效是清热泻热以及和血润燥的中药调理。具体可以服用当归贝母苦参丸，也可以煎服五味消毒饮，可以从根本上改善便秘，达到标本兼治的疗效，且不会对胎儿产生不利刺激。
